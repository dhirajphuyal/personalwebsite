# Dhiraj Phuyal — Portfolio

Astro + TypeScript portfolio site designed for static deployment on Netlify.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The production output is `dist/`.

## Deploy

Push this repository to GitHub and connect it to Netlify. `netlify.toml` already contains the build command and publish directory.

Before publishing, replace placeholder GitHub/LinkedIn links and the email address if needed.
